# FastAPI WebSocket

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/anywaymy/web-page.git
cd web-page
```

### 2. Настройка окружения
```bash
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/macOS)
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
uvicorn core.main:app --reload
```

Рабочая ссылка после запуска - http://127.0.0.1:8000
